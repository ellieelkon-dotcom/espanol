# Práctica diaria

אפליקציית תרגול ספרדית שעובדת גם בלי אינטרנט.

האפליקציה: https://ellieelkon-dotcom.github.io/espanol/

- `data/` רשימות המילים, הדקדוק וקטעי השמיעה. מתעדכן אוטומטית אחרי כל שיעור.
- ההתקדמות נשמרת רק בטלפון, לא כאן.

## הרצה מקומית

מתוך תיקיית הפרויקט:

```bash
python3 -m http.server 8181
```

ואז לפתוח את http://localhost:8181 בדפדפן. לגרסה האנגלית: http://localhost:8181/en/

- פתיחה ישירה של `index.html` מהמחשב (כתובת `file://`) לא עובדת ומציגה "הטעינה נכשלה" — הדפדפן חוסם טעינה של קבצי ה-`data/` בלי שרת.
- ההתקדמות בהרצה מקומית נשמרת בדפדפן של המחשב, בנפרד מזו שבטלפון.

## בדיקת סנכרון בין הגרסאות

`tools/check-sync.py` מוודא ש־`en/data/` לא נשאר מאחור אחרי עדכון של `data/`.

```bash
python3 tools/check-sync.py
```

הסקריפט נכשל (קוד יציאה 1) ומדפיס כל בעיה שמצא:

- מזהה כרטיס, שאלת דקדוק או קטע שמיעה שקיים רק בצד אחד, או סדר שונה בין הקבצים
- `updated` שונה ב־`deck.json`, או `focus` ו־`active` שונים ב־`grammar.json`
- תוכן שאמור להיות זהה בשתי הגרסאות ששונה ביניהן: הספרדית (`es`, `ex`), `kind`, ניסוח שאלות הדקדוק והתשובות שלהן, כותרת ותמליל של קטע שמיעה
- שדה מתורגם שמולא רק בצד אחד, או מספר שונה של שאלות ותשובות
- עברית שנשארה בקובץ האנגלי

הבדיקה רצה אוטומטית ב-GitHub Actions בכל push שנוגע ב־`data/` או ב־`en/data/`.
כדי להריץ אותה גם לפני כל קומיט מקומי:

```bash
printf '#!/bin/sh\nexec python3 tools/check-sync.py\n' > .git/hooks/pre-commit
chmod +x .git/hooks/pre-commit
```
